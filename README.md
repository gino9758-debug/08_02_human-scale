# 人为尺度

仲斌「人为尺度」思维框架 Skill——人，会再度成为尺度（Human Scale）

## 项目解决什么问题

当技术和资本的短期尺度失效后，商业和生活需要回归人的情感、经验和肉身感受这些更稳定的尺度。本技能提供一套可复用的思维工具，用于校准商业决策、产品策划、趋势判断与个人生活选择。

## 主要功能

| 能力 | 说明 |
|------|------|
| 三线均线模型 | 商业短线 / 文化中线 / 人性长线——短尺度失灵时回到更长尺度寻找支撑 |
| 基本表达理论 | 距离人类基本表达（文学/音乐/戏剧/建筑等）越近的形态生命力越强 |
| 倍速社会 × 时间贫困诊断 | 区分「增加任务密度」与「增加意义密度」两类创新方向 |
| 心安理得的慢 | 为「慢」注入意义，让时间花费变得「值得」 |
| 照料哲学 | 意义不是找出来的而是照料出来的，识别生活中的「焦点物」 |
| 意义构建飞轮 | 以「由互动自然衍生的可记录共同探索行动发生率」为黄金指标 |

## 安装方法

将本目录放入你的 Agent 技能目录（如 `~/.codex/skills/`、`~/.claude/skills/`），重启会话后生效。

### 要求
- 无第三方依赖

## 使用方法

触发场景：做商业决策/产品策划/品牌策略时用「人的尺度」校准；判断行业趋势/内容形态前景；设计消费服务/体验产品；年度规划/项目目标筛选；为家人/社区营造轻松对话氛围。

## 输入输出示例

**输入：** 用人为尺度评估这个儿童教育产品的方向
**输出：** 三线均线模型定位 + 任务密度 vs 意义密度诊断 + 照料哲学视角建议

**输入：** 分析短视频内容形态的未来
**输出：** 基本表达理论框架下的形态生命力判断
